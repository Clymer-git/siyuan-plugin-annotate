# 更新日志

版本倒序。带 `-alpha.N` 的是测试版；同一版本只保留一条记录，后续 alpha 迭代时把新改动合并进去。出正式版时换成干净版本号和发布当天日期。

## 1.3.0 · 2026-11-20

- 新增：图片右上角增加图片编辑器的入口。
- 新增：箭头新增尖尾类型和菱形、圆形两种端点。
- 优化：箭头工具栏改成类型、样式两组控件，先选箭头类型再选样式，用不到的样式会变灰。
- 优化：线调得越粗，箭头头部增长得越慢，不再跟着线宽等比放大。
- 优化：移动端箭头气泡用一条横线把类型与样式分成上下两组。
- 优化：移动端顶部的保存按钮与电脑端统一叫「保存」。
- 优化：序号取消端点的箭头 / 圆点 / 方点三选一，引线末端直接与箭头工具的端点样式同步。
- 优化：序号的圆头改成末尾一个圆线开关，与箭头一致。
- 修复：两端竖线箭头弯曲后，左侧竖线没有垂直于起点方向的问题。
- 修复：尖尾箭头拖成弧线后，线身由尾细头粗变成从头到尾一样粗的问题。
- 修复：移动端序号样式气泡的尖角没有对准按钮、气泡被撑变形的问题。

## 1.2.0 · 2026-11-19

- 新增：标注工具支持智能选择。
- 新增：文字工具可选择系统字体或上传自定义字体。
- 新增：序号工具增加空心圆、定位气泡、纯数字三种外观。
- 新增：移动端聚光灯的暗度可调。
- 优化：移动端把文字和序号的参数挪到顶部悬浮栏。
- 优化：移动端马赛克、模糊、聚光灯的滑块铺满整行。
- 优化：移动端文字输入和双指缩放更顺畅。

## 1.1.0 · 2026-11-17

- 新增：马赛克与模糊工具的选区识别。
- 新增：高亮工具的画笔与矩形两种模式。
- 新增：高亮工具的矩形标记可选中与缩放。
- 新增：移动端高亮工具的模式切换。
- 新增：移动端马赛克工具的块大小调节。
- 新增：移动端模糊工具的模糊程度调节。
- 新增：移动端马赛克与模糊工具的选区识别防误触。
- 优化：高亮工具更名为高亮。
- 优化：电脑端马赛克工具移除透明度调节。

## 1.0.0 · 2026-11-15

- 首个正式版：十一种标注、旋转翻转裁剪、扩展画布、多选对齐、手机端整屏编辑；保存覆盖原图并内嵌可编辑数据。
